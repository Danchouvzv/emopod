# EMOPOD - Эмоциональный AI-ассистент

![EMOPOD Logo](https://via.placeholder.com/150) <!-- Замените на реальный логотип -->

EMOPOD - это современный AI-ассистент, созданный для поддержки эмоционального благополучия пользователей. Проект использует передовые технологии искусственного интеллекта для анализа настроения и предоставления персонализированных рекомендаций.

## 🌟 Особенности

- 🤖 AI-чат с эмоциональной поддержкой
- 📊 Анализ настроения в реальном времени
- 💡 Персонализированные рекомендации
- 🔒 Безопасная аутентификация пользователей
- 📱 Современный и отзывчивый интерфейс
- 🌐 Поддержка русского языка

## 🚀 Технологии

- **Frontend:**
  - HTML5, CSS3
  - Tailwind CSS для стилизации
  - JavaScript (ES6+)
  - Адаптивный дизайн

- **Backend:**
  - Node.js
  - Express.js
  - MongoDB
  - Google Gemini AI API
  - JWT аутентификация

## 📋 Требования

- Node.js (v14 или выше)
- MongoDB
- API ключ Google Gemini AI
- Современный веб-браузер

## 🛠️ Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Danchouvzv/emopod.git
cd emopod
```

2. Установите зависимости:
```bash
cd emopod-web/emopod/server
npm install
```

3. Создайте файл `.env` в директории `server` со следующими переменными:
```
PORT=3000
MONGODB_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
JWT_SECRET=your_jwt_secret
```

4. Запустите сервер:
```bash
node server.js
```

5. Откройте `index.html` в вашем браузере или используйте локальный сервер для разработки.

## 📝 Использование

1. **Регистрация и вход**
   - Создайте аккаунт через форму регистрации
   - Войдите в систему используя свои учетные данные

2. **Чат с AI**
   - Откройте раздел "Чат"
   - Начните диалог с AI-ассистентом
   - Получайте эмоциональную поддержку и рекомендации

3. **История чатов**
   - Просматривайте историю ваших диалогов
   - Анализируйте изменения настроения

4. **Профиль**
   - Управляйте настройками аккаунта
   - Просматривайте статистику использования

## 🔒 Безопасность

- Все данные передаются по защищенному соединению
- Пароли хранятся в зашифрованном виде
- Используется JWT для аутентификации
- API ключи защищены от несанкционированного доступа
